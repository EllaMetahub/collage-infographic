# Palettes

Use color *names* in image prompts. Hex is for HTML/CSS type overlays and for checking a generated result.

Keep the set small: 4–6 colors plus paper cream. Do not add extra hues in the prompt.

## Default — Editorial

Paper: newsprint cream `#F7F1E5`, warm beige `#E8D5B5`
Ink: charcoal `#2B2B2B`
Accents: cobalt `#2F5AA8`, violet `#6B3FA0`, tangerine `#F07A3A`

Prompt phrase: `limited editorial palette of cobalt blue, violet, tangerine, warm beige, and newsprint cream`

Use for: unspecified requests, blog headers, knowledge explainers.

## Night column

Paper: cool ivory `#EDE6D6`
Field: deep indigo `#1E2A5A`
Accents: magenta-violet `#8B3D9C`, orange `#F07A3A`, pale cream highlights

Prompt phrase: `night-editorial collage on deep indigo paper with magenta-violet, tangerine, and ivory`

Use for: tech / night / "dark mode" topics.

## Encyclopedia

Paper: aged ivory `#F3E6C9`
Accents: muted teal `#3F6F73`, rust `#C45C26`, ochre `#D4A017`, charcoal

Prompt phrase: `encyclopedia-page collage in muted teal, rust, ochre, and aged ivory`

Use for: history, science primers, "how X works".

## Pop punch

Paper: off-white `#F6F0E4`
Accents: electric blue `#2B63D9`, hot orange `#FF6A2A`, grape `#6E2FA0`

Prompt phrase: `light-pop collage with electric blue, hot orange, grape purple, and off-white paper`

Use when the user asks for bolder pop. Still grainy paper, still collage — not a vector poster.

## Checking a result

If the image looks rainbow, neon-cyber, or earth-tone photography, it broke the palette. `image_edit` to restamp the named set.
